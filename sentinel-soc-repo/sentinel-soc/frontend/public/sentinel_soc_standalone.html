SENTINEL SOC — Mini SOC Log Analyzer & Threat Detection Platform

SENTINEL SOC is a cybersecurity log analysis and threat detection platform designed to demonstrate essential Security Operations Center workflows. It provides log ingestion, event normalization, rule-based threat detection, security alert management, incident investigation, threat intelligence enrichment, and security reporting in one unified interface. The project focuses on practical blue-team security monitoring and helping junior security analysts understand suspicious activities through structured investigation workflows.
