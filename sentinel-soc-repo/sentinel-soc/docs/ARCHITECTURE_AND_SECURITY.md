## 1. Timezone & Timestamp Standard
- All ingested timestamps (whether RFC 3164 Syslog `Nov 12 02:15:10` or ISO-8601 `2026-11-12T02:20:01Z`) are normalized to **UTC ISO-8601** (`YYYY-MM-DDTHH:MM:SSZ`) prior to database insertion and rule correlation.
- The UI and PDF/CSV/JSON reports default to **Asia/Dhaka (UTC+06:00)** display formatting, configurable in Settings.

## 2. Data Provenance & Honesty Policy
Every dataset, event, and alert carries an explicit `origin_type` column:
- `uploaded`: Real log files uploaded or pasted by the analyst.
- `sample`: Controlled demonstration files loaded via the one-click Sample Data loader.
- `simulated`: Synthetic events generated by the Live Monitoring simulator (always prefixed with `[SIMULATION MODE]`).

## 3. Threat Intelligence Privacy & Offline Operation
- Private IPv4 addresses (RFC 1918), loopback addresses, and documentation ranges (RFC 5737 `192.0.2.0/24`, `198.51.100.0/24`, `203.0.113.0/24`) are identified locally so private infrastructure telemetry is never leaked to external APIs.
- When optional external API keys (`VIRUSTOTAL_API_KEY`, `ABUSEIPDB_API_KEY`, `OTX_API_KEY`) are not configured, the platform explicitly states `Offline Mode — No API Keys Configured` and never fabricates external reputation scores.
